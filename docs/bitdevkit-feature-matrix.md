# bITdevKit Feature Matrix

This page summarizes the bITdevKit features used in this Application and where they appear in the codebase.

## Runtime Features

| Feature | Purpose in This Application | Where Used | Key Files |
| ----------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Modules](../.bdk/docs/features-modules.md) | Hosts the application as a modular monolith with `CoreModule` as a self-contained vertical slice. | Host bootstrap and module registration | [Program.cs](../src/Presentation.Web.Server/Program.cs), [CoreModuleModule.cs](../src/Modules/CoreModule/CoreModule.Presentation/CoreModuleModule.cs) |
| [Requester and Notifier](../.bdk/docs/features-requester-notifier.md) | Dispatches commands, queries, and notifications through handler pipelines with shared behaviors. | Global DI setup and handler execution | [Program.cs](../src/Presentation.Web.Server/Program.cs), [ProgramExtensions.cs](../src/Presentation.Web.Server/ProgramExtensions.cs) |
| [Application Commands and Queries](../.bdk/docs/features-application-commands-queries.md) | Implements use cases as source-generated commands and queries returning `Result<T>`. | Application layer customer workflows | [CustomerCreateCommand.cs](../src/Modules/CoreModule/CoreModule.Application/Commands/CustomerCreateCommand.cs), [CustomerDeleteCommand.cs](../src/Modules/CoreModule/CoreModule.Application/Commands/CustomerDeleteCommand.cs), [CustomerFindAllQuery.cs](../src/Modules/CoreModule/CoreModule.Application/Queries/CustomerFindAllQuery.cs) |
| [Presentation Endpoints](../.bdk/docs/features-presentation-endpoints.md) | Exposes customer CRUD/search via modular minimal API endpoint classes. | Presentation layer endpoint registration and mapping | [Program.cs](../src/Presentation.Web.Server/Program.cs), [CustomerEndpoints.cs](../src/Modules/CoreModule/CoreModule.Presentation/Web/Endpoints/CustomerEndpoints.cs) |
| [Common Mapping](../.bdk/docs/common-mapping.md) | Uses the devkit `IMapper` abstraction with Mapster for DTO, value object, and enumeration mapping. | Global mapping registration and module-specific mapping config | [Program.cs](../src/Presentation.Web.Server/Program.cs), [CoreModuleMapperRegister.cs](../src/Modules/CoreModule/CoreModule.Presentation/CoreModuleMapperRegister.cs) |
| [Domain](../.bdk/docs/features-domain.md) | Models aggregates, typed ids, value objects, smart enumerations, auditing, and concurrency in the core domain. | Customer aggregate and supporting types | [Customer.cs](../src/Modules/CoreModule/CoreModule.Domain/Model/CustomerAggregate/Customer.cs), [EmailAddress.cs](../src/Modules/CoreModule/CoreModule.Domain/Model/EmailAddress.cs), [CustomerStatus.cs](../src/Modules/CoreModule/CoreModule.Domain/Model/CustomerAggregate/CustomerStatus.cs) |
| [Domain Events](../.bdk/docs/features-domain-events.md) | Records business-significant events in aggregates and processes them after persistence. | Aggregate event registration, outbox persistence, and handlers | [Customer.cs](../src/Modules/CoreModule/CoreModule.Domain/Model/CustomerAggregate/Customer.cs), [CoreModuleModule.cs](../src/Modules/CoreModule/CoreModule.Presentation/CoreModuleModule.cs), [CustomerCreatedDomainEventHandler.cs](../src/Modules/CoreModule/CoreModule.Application/Events/CustomerCreatedDomainEventHandler.cs) |
| [Domain Repositories](../.bdk/docs/features-domain-repositories.md) | Accesses aggregates through `IGenericRepository<TEntity>` instead of direct `DbContext` use in application code. | Application handlers, startup tasks, jobs | [CustomerCreateCommand.cs](../src/Modules/CoreModule/CoreModule.Application/Commands/CustomerCreateCommand.cs), [CustomerFindAllQuery.cs](../src/Modules/CoreModule/CoreModule.Application/Queries/CustomerFindAllQuery.cs), [CoreModuleDomainSeederTask.cs](../src/Modules/CoreModule/CoreModule.Application/CoreModuleDomainSeederTask.cs) |
| [Filtering](../.bdk/docs/features-filtering.md) | Supports API filtering, sorting, and paging through `FilterModel` passed into repository queries. | Customer list and search endpoints | [CustomerEndpoints.cs](../src/Modules/CoreModule/CoreModule.Presentation/Web/Endpoints/CustomerEndpoints.cs), [CustomerFindAllQuery.cs](../src/Modules/CoreModule/CoreModule.Application/Queries/CustomerFindAllQuery.cs) |
| [Results](../.bdk/docs/features-results.md) | Uses `Result` and `Result<T>` as the main success/failure contract across domain, application, and presentation mapping. | Domain factories/mutations and application handlers | [Customer.cs](../src/Modules/CoreModule/CoreModule.Domain/Model/CustomerAggregate/Customer.cs), [EmailAddress.cs](../src/Modules/CoreModule/CoreModule.Domain/Model/EmailAddress.cs), [CustomerCreateCommand.cs](../src/Modules/CoreModule/CoreModule.Application/Commands/CustomerCreateCommand.cs) |
| [Rules](../.bdk/docs/features-rules.md) | Applies composable rule checks for business validation beyond simple input validation. | Domain and application validation flows | [EmailAddress.cs](../src/Modules/CoreModule/CoreModule.Domain/Model/EmailAddress.cs), [Customer.cs](../src/Modules/CoreModule/CoreModule.Domain/Model/CustomerAggregate/Customer.cs), [EmailShouldBeUniqueRule.cs](../src/Modules/CoreModule/CoreModule.Application/Rules/EmailShouldBeUniqueRule.cs) |
| [StartupTasks](../.bdk/docs/features-startuptasks.md) | Seeds sample customer data after the database is ready in local/containerized environments. | Core module startup registration | [CoreModuleModule.cs](../src/Modules/CoreModule/CoreModule.Presentation/CoreModuleModule.cs), [CoreModuleDomainSeederTask.cs](../src/Modules/CoreModule/CoreModule.Application/CoreModuleDomainSeederTask.cs) |
| [Jobs](../.bdk/docs/features-jobs.md) | Runs durable scheduled jobs with EF persistence, retry/concurrency policies, endpoints, console commands, metrics, dashboard pages, and MCP handlers. | CoreModule job registration and execution | [CoreModuleModule.cs](../src/Modules/CoreModule/CoreModule.Presentation/CoreModuleModule.cs), [CustomerExportJob.cs](../src/Modules/CoreModule/CoreModule.Application/Jobs/CustomerExportJob.cs), [CoreModuleDbContext.cs](../src/Modules/CoreModule/CoreModule.Infrastructure/EntityFramework/CoreModuleDbContext.cs) |
| [Dashboard](../.bdk/docs/features-presentation-dashboard.md) | Hosts protected DevKit operational pages and the application-specific customer management page. | Host dashboard registration and CoreModule plugin | [ProgramExtensions.Authentication.cs](../src/Presentation.Web.Server/ProgramExtensions.Authentication.cs), [CoreModuleDashboard.cs](../src/Modules/CoreModule/CoreModule.Presentation/Dashboard/CoreModuleDashboard.cs) |
| [Metrics](../.bdk/docs/features-metrics.md) | Records request, handler, repository, job, ASP.NET Core, HTTP client, and runtime metrics. | Host metrics and OpenTelemetry setup | [Program.cs](../src/Presentation.Web.Server/Program.cs), [ProgramExtensions.Observability.cs](../src/Presentation.Web.Server/ProgramExtensions.Observability.cs), [CoreModuleModule.cs](../src/Modules/CoreModule/CoreModule.Presentation/CoreModuleModule.cs) |
| [Profiling](../.bdk/docs/features-profiling.md) | Captures bounded in-memory process samples in development and exposes the Profiling dashboard page and console commands. | Development diagnostics | [Program.cs](../src/Presentation.Web.Server/Program.cs) |
| [Fake Identity Provider](../.bdk/docs/features-identityprovider.md) | Provides local OAuth2/OIDC authentication for development and API testing. | Host auth setup and local dev identity provider | [Program.cs](../src/Presentation.Web.Server/Program.cs), [ProgramExtensions.cs](../src/Presentation.Web.Server/ProgramExtensions.cs) |
| [Console Commands](../.bdk/docs/features-presentation-console-commands.md) | Enables the interactive console shell and job-related operational commands. | Host startup and scheduler integration | [Program.cs](../src/Presentation.Web.Server/Program.cs) |
| [Exception Handling](../.bdk/docs/features-presentation-exception-handling.md) | Converts failures into Problem Details responses through devkit presentation helpers. | Host service registration and middleware pipeline | [Program.cs](../src/Presentation.Web.Server/Program.cs), [ProgramExtensions.cs](../src/Presentation.Web.Server/ProgramExtensions.cs) |
